# Public Results

This directory contains publication-facing figures and aggregate analytical
outputs generated by the current analysis pipeline.

The complete local `output/` directory is intentionally excluded from version
control because it also contains person-level analytical and audit files.

Only outputs that do not expose editor identities or restricted adjudication
information are included here.

The authoritative machine-generated numerical summary is:

`tables/manuscript_results_manifest.csv`

The files in this directory are derived outputs and should be regenerated from
the current pipeline before an archival release.
